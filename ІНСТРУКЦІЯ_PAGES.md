# Версія для GitHub Pages (iPhone та будь-який телефон)

Окрема копія застосунку. Вона використовує **ті самі** ключ TMDB і базу Firebase, що й Android-версія, тому списки та коди кабінетів спільні. Мова за замовчуванням українська; при першому запуску показується коротке вступне вікно.

## 1. Репозиторій
1. GitHub → New repository → **Public** (на безкоштовному тарифі Pages працює лише з публічними).
2. Завантажте **папку `site` цілком** (перетягніть саму папку, а не її вміст) та `README.md`.
3. Створіть файл `.github/workflows/pages.yml` (Add file → Create new file) і вставте вміст файлу `pages.yml` з архіву. Commit.

## 2. Pages
Settings → Pages → Source: **GitHub Actions**. Потім Actions → Deploy Pages → Run workflow. За 1–2 хвилини сайт буде за адресою `https://ваш-логін.github.io/назва-репозиторію/`.

## 3. iPhone
Відкрийте посилання в **Safari** → «Поділитися» → «На екран “Додому”». Введіть ім’я та **той самий код кабінету**, що й на Android.

## Важливо про ключі
Репозиторій публічний, тому ключ TMDB і конфіг Firebase у `site/config.js` видно всім. Для застосунку з Firebase це звичайна практика (конфіг і так потрапляє в кожен APK), але:
- не кладіть сюди ключ підпису APK та інші секрети;
- код кабінету працює як пароль: не публікуйте його;
- якщо ключ TMDB «витече», замініть його на themoviedb.org і оновіть `config.js` в обох репозиторіях.

## Оновлення
Завантажте нові файли в `site/` (з тими самими іменами) і зробіть commit: сторінка оновиться сама. Якщо видно стару версію, закрийте й відкрийте застосунок: з’явиться плашка «Оновити».
