# Версія для GitHub Pages (iPhone та будь-який телефон)

Окрема копія застосунку для GitHub Pages. Вона використовує **ті самі** ключ TMDB і базу Firebase, що й Android-версія, тому списки та коди кабінетів спільні. Мова за замовчуванням: українська; при першому запуску показується коротке вступне вікно.

## 1. Створіть репозиторій
1. GitHub → **New repository** → назва, наприклад `nashi-serialy-web` → **Public** (на безкоштовному тарифі Pages працює лише з публічними) → Create.
2. **Add file → Upload files**: завантажте папку `site` та `README.md`.
3. Приховану папку `.github` завантажити не вийде: **Add file → Create new file**, ім’я `.github/workflows/pages.yml`, вставте вміст файлу `pages.yml` із цього архіву. Commit.

## 2. Увімкніть Pages
**Settings → Pages → Source: GitHub Actions.** За 1–2 хвилини в **Actions** з’явиться зелена збірка, а в Settings → Pages посилання на кшталт `https://ваш-логін.github.io/nashi-serialy-web/`.

## 3. iPhone
Відкрийте посилання в **Safari** → «Поділитися» → «На екран “Додому”». Введіть ім’я та **той самий код кабінету**, що й на Android.

## Важливо про ключі
Репозиторій публічний, тому ключ TMDB і конфіг Firebase у `site/config.js` видно всім. Для застосунку з Firebase це звичайна практика (конфіг і так потрапляє в кожен APK), але:
- не кладіть сюди ключ підпису APK та інші секрети (вони лишаються в окремому приватному репозиторії);
- код кабінету працює як пароль: не публікуйте його;
- якщо ключ TMDB колись «витече», його можна замінити на themoviedb.org та оновити `config.js` в обох репозиторіях.

## Оновлення
Завантажте нові файли в `site/` і зробіть commit: сторінка оновиться сама. Якщо на телефоні стара версія, закрийте й відкрийте застосунок двічі.
